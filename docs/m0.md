# M0 smoke sequence

Deterministic Soft script `soft/rogue/m0_smoke.aura`. Seed `20261005`,
four rooms. Dialect string: `soft-rogue-m0`.

One player, integer HP/ATK. Two drop/AI packs. The numbers are the race.

## Law

1. Seed step: `(modulo (+ (* seed 75) 74) 65537)`. This seed steps to
   `34567`, so the shared start is `hp=11 atk=3`.
2. Room enemies (index → ehp, eatk): `0→(5,2) 1→(7,3) 2→(10,4) 3→(14,5)`.
3. Each exchange: player deals `atk` first. If the enemy still has HP,
   it deals `max(1, qdiv(raw-atk, ai-div))`.
4. `qdiv` is toward-zero quotient.
5. A clear applies loot `(loot-hp, loot-atk)` then advances the room.
6. Player HP ≤ 0 is death. That room is not committed and does not
   increment `alive`.
7. Score is `(+ (* alive 1000000) clarity)` where `clarity` is remaining
   HP (0 on death). Clarity on this dungeon stays below 1000000, so
   `quotient(score, 1000000)` is `alive`.

## Packs

| mid | name | loot HP | loot ATK | ai-div |
|-----|------|---------|----------|--------|
| 1 | `rules-greedy` | 1 | 2 | 1 (aggressive) |
| 2 | `rules-safe` | 4 | 0 | 2 (timid) |

Greedy dies in room 4 (3 rooms cleared). Safe clears all 4 with HP 10.
Neither body calls `set-code`. M0 does not `hot-strategy:register!` them.

## Race

Same seed, both packs. The race thunks only return a score. They do not
`set!` the main slot, so a real fiber cannot publish the loser's HP into
the live world.

`fiber:spawn` both thunks, then `fiber:join`. `fiber_live` only when the
ids are distinct and positive, both joins are numbers, `joins` equals
`spawned`, and `fiber:spawn-backend` is `> 0`. Otherwise the thunks run
on the host and the stamp is `host-sequential`.

The greater score wins. A survival tie would break on clarity. A full
tie would KEEP greedy (`tie-keep-greedy-stamp`). This seed is not a tie.

The winner is replayed with the tape flag on. The loser is not replayed.
That is the rollback.

`backend=2` is the CLI thread fallback, not serve-async. If a future
binary joins nothing, the same script must print `host-sequential` and
must not print `fiber_live`. The smoke accepts either honest line.
`fiber_live` without `joins=2/2` is a failure.
