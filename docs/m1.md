# M1 — hot-strategy and an honest worldline

`soft/rogue/m1_smoke.aura`. Seed `20261005`. M0 is unchanged: it does not
load this path and still races greedy vs safe without `hot-strategy`.

## What M1 guarantees

1. `rg:law` is a real `std/hot-strategy` slot. Seed is `set-code` plus
   `hot-strategy:register!`. A later body goes in with `hot-strategy:swap!`.
   `hot-strategy:heal!` restores the pre-swap snapshot. This is not a
   renamed `set!`. The body is `(lambda () (list loot-hp loot-atk ai-div))`.
2. The slot can change **mid-run**. Two rooms run on the seed safe pack.
   A `set!` body is gate-rejected and the room count stays 2. A tanky body
   is swapped in (`SWAP name=rg:law room=2`). One more room runs on that
   body (`room=3`). An ugly body that returns a short list fails the pack
   probe, `heal!` runs, and room is still 3. Prior rooms are not retconned.
3. Heal restores the last good snapshot, which is the tanky body, not the
   original safe seed. `(rg:law)` is `(6 1 2)` after that heal.
4. At live room 2 the world prints `MUTATE room=2 loot-boost=1` and raises
   `*loot-boost*`. That is a Soft mutation log, not `mutate:rebind`.
5. The dual race is still `rules-greedy` vs `rules-safe` on the same seed,
   separate from the hot-slot demo. `KEEP` / `DROP` use the greater score.
   This seed keeps safe.
6. `fiber_live` is printed only when that race spawned two distinct
   positive fiber ids and both `fiber:join`s returned a number, and
   `fiber:spawn-backend` is > 0. Otherwise the same two thunks run on the
   host and the line is `host-sequential`. A missed join is not labeled
   `fiber_live`.

## Measured on this tip

`bash scripts/smoke_m1.sh` against `/workspace/aura-grok/build/aura`:

| line | value |
|------|--------|
| `MUTATE` | `room=2 loot-boost=1 slot=rg:law` |
| `SWAP` | `name=rg:law room=2 reason=mid-swap` |
| `HEAL` | `name=rg:law room=3 reason=probe` |
| `RACE` | `greedy=3000000 safe=4000010` |
| `WORLD` | `line=fiber_live backend=2 joins=2/2` |
| `KEEP` | `mid=2 reason=longer-survival-stamp` |
| `DROP` | `mid=1 reason=shorter-survival-rollback` |
| end | `ROGUE_M1_OK` |

`backend=2` is the CLI thread fallback (`fiber:spawn-backend`), not the
serve-async scheduler (`backend=1`). Joins landed and the scores match the
M0 tape, so the stamp is `fiber_live`. If a future binary returns `#f`
from spawn or join, this smoke still passes with `host-sequential` and
must not say `fiber_live`.

## 中文

M1 在第 2 房后 `hot-strategy:swap!` 换掉落/AI 规则包，第 3 房用
`hot-strategy:heal!` 拉回上一份好快照。房间数不被 swap 清掉。第 2 房印
`MUTATE room=2 loot-boost=1`。`rules-greedy` 对 `rules-safe` 的双世界线：
这次二进制上两条 fiber 都 join 成功，所以印
`fiber_live backend=2 joins=2/2`。backend 2 是 CLI 线程回退，不是
serve-async。没 join 就不印 `fiber_live`。M0 仍然不加载本文件。
